## 能做什么

- 从相册选体检单、化验单的照片或 PDF，识别出每一项指标和参考范围，核对后存好
- 爸妈、孩子、自己各有档案，按家人长期整理
- 每项指标按日期看趋势，几份报告并排对比
- 原件和指标加密存在手机上；云同步端到端加密，服务器只存密文

仅用于记录和整理，不构成医疗建议。
